# Black Ant Academy - Website Resmi Academy Beladiri Sidoarjo

Selamat datang di repository resmi website **Black Ant Academy**, akademi beladiri & pusat kebugaran terkemuka di Sidoarjo yang menyediakan pelatihan **Muay Thai, Kickboxing, Boxing, MMA, Brazilian Jiu-Jitsu (BJJ), Wushu Sanda,** dan **Functional Training**.

Website ini dirancang untuk memberikan pengalaman digital modern, responsif, dan interaktif bagi calon member dan atlet yang ingin mendaftar kelas, melihat jadwal latihan, hingga berkonsultasi langsung dengan tim admin/pelatih.

---

## 🌟 Fitur & Keunggulan Utama

### 1. 🏠 Halaman Beranda (Home)
- **Hero Banner Dynamic**: Menampilkan atmosfer latihan aktual dengan Call To Action (CTA) pendaftaran Free Trial.
- **Showcase Program Pilihan**: Ringkasan kelas beladiri unggulan dengan foto resolusi tinggi.
- **Profil Pelatih & Fasilitas**: Pengenalan pelatih berlisensi nasional dan fasilitas gym.
- **FAQ Interaktif**: Pertanyaan umum seputar pendaftaran, perlengkapan latihan, dan kelas pemula.

### 2. 🥋 Program Beladiri & Detail Kelas (`/programs`)
- **Multi-Disiplin**: Detail komprehensif untuk program Muay Thai, Kickboxing, MMA, BJJ, Wushu Sanda, dan Functional Training.
- **Tingkat Kesulitan**: Informasi tingkat level (Pemula, Menengah, Atlet/Kompetisi).
- **Halaman Detail Program (`/programs/:slug`)**: Penjelasan teknik, manfaat kesehatan, kurikulum latihan, dan galeri foto.

### 3. 📅 Jadwal Latihan Interaktif (`/schedule`)
- **Tiga Slot Harian**: Pagi (09:00 - 10:30), Sore (16:00 - 17:30), dan Malam (19:00 - 21:00).
- **Filter Disiplin**: Kemudahan menyaring jadwal berdasarkan jenis beladiri yang diminati.

### 4. 💳 Paket Keanggotaan & Harga (`/pricing`)
- **Pilihan Fleksibel**: Informasi paket bulanan, insidental (per visit), dan paket privat.
- **Integrasi Pendaftaran**: Tombol klaim promo dan pendaftaran trial langsung mengarah ke sistem registrasi.

### 5. 🤖 Anty Bot - Floating Virtual Assistant (`WhatsAppFloat.tsx`)
- **Interactive Chat Assistant**: Widget chat terapung dengan karakter ikonik "Anty".
- **Quick Reply Chips**: Respon cepat untuk info jadwal, harga, lokasi gym, dan cara klaim Free Trial.
- **Direct WhatsApp Gateway**: Menghubungkan calon member langsung ke nomor WhatsApp Admin resmi (`+62 857-4518-6832`) dengan pesan terformat otomatis.

### 6. 🌐 Dukungan Multi-Bahasa (Bilingual ID/EN)
- Toggle bahasa fleksibel antara **Bahasa Indonesia** dan **English** di seluruh komponen dan teks website.

### 7. 🌓 Mode Gelap & Terang (Dark / Light Mode)
- **Theme Switcher**: Penyesuaian tema visual yang nyaman di mata dengan kontras warna yang diperhitungkan secara presisi untuk kenyamanan membaca.

### 8. 📝 Form Pendaftaran Free Trial (`/trial`)
- Formulir pendaftaran sesi uji coba gratis dengan pilihan cabang beladiri, tanggal latihan, serta integrasi konfirmasi via WhatsApp.

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animations**: Motion (`motion/react`)
- **Icons**: Lucide React
- **Routing**: React Router DOM (Single Page Application)
